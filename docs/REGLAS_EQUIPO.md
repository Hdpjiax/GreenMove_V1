# Reglas de trabajo

- No trabajar directamente en main.
- Una rama por tarea.
- Commits pequeños.
- No agregar dependencias sin avisar.
- No modificar archivos ajenos sin avisar.
- Probar antes de hacer commit.
- Actualizar TAREAS.md cuando corresponda.

## Ejemplos de commit
- feat: agrega formulario de registro
- feat: crea modelo de publicacion
- fix: corrige validacion de correo
- style: ajusta tarjetas del muro
- docs: actualiza contrato de api
