# API Greenmove

Este documento es el contrato humano inicial entre frontend y backend. El contrato ejecutable vivira en `docs/openapi.yaml`.

## Reglas

Antes de cambiar una ruta, nombre de dato o tipo:

1. Actualizar `docs/API.md`.
2. Actualizar `docs/openapi.yaml`.
3. Ajustar backend/frontend.
4. Ejecutar pruebas.

## Tipos de publicacion

| Codigo | Etiqueta | Uso |
| --- | --- | --- |
| `UBER_SPLIT` | Comparto Uber | Un estudiante ya tomara Uber y busca dividir costo. |
| `OWN_CAR` | Tengo auto | Un estudiante ofrece lugares en su auto con cooperacion voluntaria. |
| `RIDE_REQUEST` | Necesito raite | Un estudiante solicita que alguien pase por el. |

Estos codigos son la fuente de verdad para backend, frontend, base de datos y pruebas.
