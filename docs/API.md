# Contrato simple de API

Este archivo lo usan frontend y backend para ponerse de acuerdo.

## Regla
Antes de cambiar una ruta o nombre de dato:
1. Backend propone.
2. Frontend confirma impacto.
3. Se actualiza este documento.
4. Después se cambia el código.
