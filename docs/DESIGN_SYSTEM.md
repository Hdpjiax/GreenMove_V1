# Greenmove Design System

Este documento congela la direccion visual para fases futuras. En la fase de base tecnica no se implementan componentes, tokens ni pantallas.

## Identidad

- Mobile-first .
- Lenguaje visual: neo-brutalist pop .
- La referencia de Stitch guia el lenguaje visual, pero no se copia HTML generado como produccion.

## Reglas

- No implementar diseno hasta que la tarea lo pida explicitamente.
- Priorizar 360, 390 y 430 px antes de tablet/escritorio.
- Cubrir estados de carga, vacio, error, offline, exito y permisos denegados.
- Mantener objetivos tactiles de al menos 44x44 px y foco visible.
- Usar solamente los tipos `PRIVATE_CAR_SPLIT`, `OWN_CAR` y `RIDE_REQUEST`.
